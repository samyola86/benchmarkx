# Branding and interface assets

- `logo.png`: BenchMark X wordmark, embedded as the app logo.
- `favcon.png`: supplied application symbol, embedded for use where appropriate.
- `BenchMarkX.ico`: multi-size application, window, installer and tray icon.
- `hardware/`: representative CPU/GPU, memory, storage, network and sensor artwork, selected using actual detected hardware and adapter identity.

These assets are tracked with the source. The artwork is representative rather than an exact photograph of the installed product. Vendor marks identify compatible hardware and do not imply affiliation or endorsement. No additional license for original branding or artwork is granted by this file.
